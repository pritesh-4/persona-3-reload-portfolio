# Audio included in this pack

The following WAV files are **original, synthesized implementation/test assets** created for this portfolio prototype. They are not Persona 3 Reload recordings, samples, remixes, recreations, or OST substitutes.

- `bgm-placeholder-original-not-persona3.wav` — 24-second soft ambient loop placeholder for testing the BGM player.
- `ui-select-original.wav` — short selection tick.
- `ui-confirm-original.wav` — confirmation cue.
- `ui-back-original.wav` — back/cancel cue.
- `ui-transition-original.wav` — transition sweep.

Replace the placeholder BGM with an audio master and composition for which the website has an explicit licence. A consumer OST purchase, Spotify Premium subscription, or Apple Music subscription does not itself grant a website background-music/synchronisation licence.
