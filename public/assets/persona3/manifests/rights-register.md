# Persona 3 Reload Portfolio Asset Rights & Source Register

## 1. Overview & Intellectual Property
All characters, logos, music, trademarks, and visual designs of **Persona 3 Reload** are the intellectual property of **ATLUS Co., Ltd.** and **SEGA Corporation**.

This repository contains:
1. **Acquired Official Character Artwork**: Retrieved from the public official SEGA Asia portal for educational, prototype, and evaluation purposes.
2. **Presentation Key Visuals & References**: High-resolution promotional key art and UI design references.
3. **Original Synthesized Audio Test Assets**: 100% original, non-sampled audio cues and ambient background bed created explicitly for interactive UI testing without infringing game audio copyrights.

## 4. Audio Clearance Policy
As mandated by intellectual property law and video game asset management standards:
- **No commercial game soundtrack rips** are bundled in this project.
- The web application provides a full-featured HTML5 audio controller supporting play/pause, looping, smooth volume scaling, and mute.
- When an official web synchronization license or streaming embed is approved, the audio source path can be seamlessly plugged into `src/config/personaAssets.ts`.
